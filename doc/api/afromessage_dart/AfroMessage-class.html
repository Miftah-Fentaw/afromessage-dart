AfroMessage

AfroMessage class

Dart client for the AfroMessage Ethiopian SMS API.

Mirrors the Node.js afromessage package: send SMS, bulk SMS, OTPs, and verify codes.

final sms = AfroMessage(
  AfroMessageConfig(
    apiKey: 'YOUR_TOKEN',
    senderName: 'YOUR_SENDER',
    identifierId: 'YOUR_IDENTIFIER',
  ),
);

final result = await sms.sendSms(
  SendSmsRequest(to: '0912345678', message: 'Hello from Dart'),
);
