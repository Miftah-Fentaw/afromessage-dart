# afromessage_dart demo

Flutter sample for [`afromessage_dart`](../). Uses a path dependency and is **not** published to pub.dev.

```bash
cd demo_app
flutter pub get
flutter run   # Android or desktop preferred
```

- Enter your own API key at runtime (memory only — never committed).
- Enable **Mock mode** to try the UI without calling the API.
- Prefer backend integration in production apps.
